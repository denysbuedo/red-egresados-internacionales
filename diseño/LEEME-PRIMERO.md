# CONECTA | Kit de identidad visual v1.0

**Propuesta de marca:** conecta. — Ecosistema digital de la educación superior cubana.

**URL institucional actual:** https://conecta.reduniv.edu.cu/

## Carpeta por carpeta
1. `01_Logotipos`: SVG editables y PNG listos para uso, favicon.ico, isotipo y logotipos para fondos claros/oscuros.
2. `02_Colores`: carta de color, archivos CSS y JSON.
3. `03_Tipografia`: Inter e IBM Plex Mono; hojas CSS, enlaces para obtenerlas legalmente y recomendaciones. *No se adjuntan archivos de fuente*.
4. `04_Textos`: propuesta de textos para portada, acceso, comunidad, mensajes de interfaz, SEO y difusión.
5. `05_Recursos_Digitales`: banners, imagen para compartir en redes, avatares y portada web demostrativa no funcional.
6. `06_Manual`: guía de uso de marca en PDF y versión HTML.
7. `07_Desarrollo`: CSS y guía de integración para el equipo de desarrollo.

## Identidad

## Recomendaciones de lanzamiento
- Mantener la URL existente mientras se valida el cambio visual.
- Comprobar aprobación institucional de la identidad y no confundir módulos previstos con módulos implementados.
- Garantizar cumplimiento de los estatutos y políticas de acceso vigentes.
- Antes de un cambio irreversible, comprobar disponibilidad y posibles conflictos de marcas.
- *Importante*: este es un paquete creativo original de propuesta, no una certificación de marca registrada.
