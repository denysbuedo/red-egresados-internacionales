# CONECTA | Sistema tipográfico

## Fuente principal: Inter
- Logo (versión SVG con texto editable): Inter Bold/ExtraBold 700-800.
- Titulares: Inter 700 u 800.
- Subtítulos: Inter 600-700.
- Cuerpo: Inter 400, interlineado 1.5 a 1.65.
- Botones: Inter 600.

**Fuente secundaria para código:** IBM Plex Mono 400 y 500.

### Obtener las fuentes de forma oficial
- Inter: https://github.com/rsms/inter/releases/latest
- Inter (Google Fonts): https://fonts.google.com/specimen/Inter
- IBM Plex Mono: https://github.com/IBM/plex/
- IBM Plex Mono (Google Fonts): https://fonts.google.com/specimen/IBM+Plex+Mono

Ambas familias son de código abierto (licencia SIL Open Font License). Verificar los términos aplicables en la distribución oficial al instalarlas.

**Nota:** No se redistribuyen los archivos TTF/OTF/WOFF en este paquete. Se ofrecen los enlaces oficiales y el archivo `fuentes-web.css` para integrarlas. Los SVG vectoriales con contornos no requieren fuentes instaladas; las variantes editables sí necesitan Inter.
